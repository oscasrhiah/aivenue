# 量測 Aivenue 共享上下文使用效率：給另一台電腦上的 Claude 的引導

請把這份引導和同一個資料夾裡的 `measure.mjs` 一起交給那台電腦上的 Claude。

---

## 給 Claude 的指示

你要量測這台電腦上 Aivenue 工作流的共享上下文使用效率，產生一份報告交給使用者。

### 規則

- **只讀**：不要修改、移動或刪除 Aivenue 資料夾（預設 `~/.aivenue`，Windows 是 `%USERPROFILE%\.aivenue`）裡的任何檔案。報告寫到資料夾外面。
- 量測時不要停止正在執行的 Aivenue 或工作流。腳本只讀檔，可以在工作流執行中跑。
- 報告會遮蔽金鑰、token 與家目錄路徑。交給使用者前，請再檢查一遍，確認報告裡沒有密碼、金鑰、帳號或私人資料。有疑慮就改成 `***`。
- 不要把記錄原文貼進報告。報告只需要統計數字，加上已經遮蔽過的指令摘要。

### 步驟

1. 確認有 Node.js 18 以上：`node --version`。
2. 找出 Aivenue 的資料夾：如果有設定 `AIVENUE_HOME` 環境變數，就用那個路徑；沒有的話就是 `~/.aivenue`。裡面應該有 `runs/` 資料夾。
3. 找出要量的工作流：`runs/` 底下每個資料夾是一個工作流，資料夾名稱開頭是開始時間，例如 `20261028200031-2eff5d`。請使用者指定，或挑執行最久、agent 最多的那幾個。
   - 可以用 `run.json` 裡的 `config.title` 看標題。
   - `events/` 裡的檔案總大小可以看出規模。
4. 執行腳本，在一個空的工作資料夾裡跑（不要在 Aivenue 資料夾裡跑）：
   ```bash
   node measure.mjs --run <工作流資料夾名稱> --out report.md
   ```
   - 量最近 3 個工作流：`node measure.mjs --last 3 --out report.md`
   - 資料夾不在預設位置時，加上 `--home <路徑>`。
   - 如果事件記錄很大（數 GB）、跑太久，先只量一個工作流。
5. 看一下報告，用三到五句話補充你觀察到的情況，例如：
   - 重複最多的是哪一類指令（測試、建置、讀檔、看環境）。
   - 是同一個 agent 自己重跑，還是不同 agent 互相重跑。
   - `read_context`／`search_records`／`post_note` 有沒有人用。
   - 共享區塊有多大、有沒有被截斷。
   - agent 自己壓縮對話的次數。
6. 把 `report.md` 加上你的補充，交給使用者。

### 腳本量了什麼

| 項目 | 意義 |
|---|---|
| 重複的指令 | 同一條指令被再跑一次。如果中間沒有任何檔案被修改，舊結果其實還能用，就算「浪費」。 |
| 輪詢 | 等背景工作的指令（`sleep`、`until`、`while`、`pgrep`、`date`，或讀 `.log`／`.out`／`.err`／`.exit_code`）重跑，另外計數，不算浪費。 |
| 由沒跑過的 agent 重跑 | 別的 agent 跑過、而且檔案沒變，這個 agent 卻自己又跑一次。這是共享上下文本來應該省下的部分。 |
| 改檔 | 編輯工具，加上會改檔的 shell 指令（`sed -i`、`>` 重新導向、`tee`、`mv`／`cp`／`rm`、`git checkout` 等）。 |
| 重讀檔案 | 同一個檔案在沒被修改的情況下又被讀一次。只讀一個檔案的 `cat`／`sed -n`／`head`／`tail` 也算讀檔；重讀 log 類檔案另外計數，不算浪費。 |
| 共享工具的使用次數 | `read_context`、`search_records`、`post_note` 等工具被呼叫的次數。 |
| 共享區塊大小 | 每次交給 agent 的提示詞裡，「SHARED CONTEXT」那一段有多長，以及有沒有因為模型放不下而被截斷。 |
| 記錄的工具輸出總量 | 如果不截短，總共有多少內容可以共享。 |
| agent 自己壓縮對話 | 從 CLI 回報的上下文用量突然下降來判斷。不是每個 CLI 都會回報，所以可能偏少。 |

指令判斷是否相同時，會忽略開頭的 `cd 某資料夾 &&`、引號與多餘的空白。

「中間有沒有改檔」看的是整個工作流有沒有任何改檔，不分是哪個檔案。所以只要有 agent 把訓練 log 之類的東西寫進檔案，其他重複就不會被算成浪費，「浪費」的數字可能略為偏低。背景程序自己寫的檔案看不到，也不算改檔。

# Aivenue for VS Code

讓你手上的多家 AI coding 工具（Claude Code、Codex、Antigravity、GitHub Copilot、OpenCode、Qwen Code…）在同一個工作流裡分工合作：一家寫計畫、另一家審查；一家實作、另一家驗收；任何一家在工作中還能把子任務派給其他家當 sub agent。全程在 VS Code 右側面板即時顯示進度，中間的編輯器留給你看程式碼。

使用的是你自己的訂閱帳號（或 API 金鑰），各家 CLI 用官方的瀏覽器流程登入，Aivenue 不會經手你的帳號密碼。

---

## 系統需求

| 項目 | 說明 |
|---|---|
| VS Code | 1.143 以上（Aivenue 顯示在右側的次要側邊欄；舊版可用「在編輯器分頁中開啟」） |
| AI CLI | 至少一家，安裝在**這台電腦**上並登入（見下方「支援的工具」）。插件的「設定 → 供應商」有安裝與登入按鈕 |
| 其他 | **不需要**安裝 Aivenue 桌面 App，也不需要另外安裝 Node.js；插件自帶完整的引擎。用「隔離模式」時需要 git |

## 安裝

1. VS Code → 擴充功能 → 右上角「⋯」→「從 VSIX 安裝…」，選擇 `aivenue-vscode.vsix`
   （或在終端機執行 `code --install-extension aivenue-vscode.vsix`）
2. 安裝後狀態列左下會出現「Aivenue」，右側次要側邊欄會多一個 Aivenue 圖示

## 開始使用

1. **打開 Aivenue**：點狀態列的「Aivenue」，或命令面板（Ctrl+Shift+P）執行「Aivenue: 開啟 Aivenue」。
2. **登入工具**：右上角 ⚙ →「供應商與帳號」。每家都有「安裝」「登入」按鈕；登入會開一個終端機執行該工具自己的登入指令，在瀏覽器完成即可。也可以切換成「API」並填金鑰。
3. **選角色**：輸入框裡的「⚙ 角色」按鈕 → 選「自動指派」（Aivenue 依能力與額度幫你分配）或「自訂指派」（自己選每個角色由誰做、用什麼模型）。
4. **選權限**：輸入框裡的權限按鈕（例如「⚡ 完全 Auto」）→ 選要讓 agent 自己動手到什麼程度。
5. **輸入任務並送出**（Enter 送出、Shift+Enter 換行）。工作資料夾預設是目前開啟的專案。

## 介面說明

**輸入框**只放三個按鈕，其他設定都在跳出的視窗裡：

| 按鈕 | 作用 |
|---|---|
| 📎 附件 | 選擇檔案；也可以直接拖曳或貼上（Ctrl+V 截圖） |
| ⚡ / ✋ / ✏️ / 📋 權限 | 點一下選權限等級，也可勾選「隔離模式」 |
| ⚙ 角色 | 開啟「工作流設定」視窗：自動／自訂指派、每個角色的供應商與模型、計畫／實作／審查開關、審查回合數、sub agent、顧問模式、上下文分享、工作資料夾、常用組合 |

右下角的送出按鈕會隨狀態變化：平常是 **↑ 送出**；agent 工作中變成 **❚❚ 暫停**；暫停後變成 **▶ 繼續**（見下方「對話中的控制」）。

**對話畫面**

- 每個 agent 一張卡片：誰（哪一家、實際使用的模型，例如「Opus 5.5」「GPT-6 Astra」、推理強度）、在第幾輪、讀了哪些檔、改了什麼、跑了什麼指令，執行中會即時更新；「完整紀錄」可展開全部步驟。
- 審查結果會列出每一個問題（嚴重／重要／次要），作者的回應（已修正或反駁）也會顯示。
- **進度清單**固定在輸入框上方：撰寫計畫 → 審查計畫 → 實作（底下列出計畫的每一步）→ 審查程式碼，打勾、進行中、尚未開始一目了然。
- **最終結果**：審查通過後，最後的回答會整理成一張卡片顯示在對話最下方。
- **這次產生或修改的檔案**：列出新增／修改／刪除的檔案，可「預覽」「開啟」（在中間編輯器開啟）「所在資料夾」。
- 左上 ☰ 是對話紀錄，＋ 是新對話，⚙ 是設定。
- 面板上方的 ↗ 可以改在編輯器分頁中開啟（寬版面），🌐 可在瀏覽器中開啟。

## 工作流程與角色

```
撰寫計畫 ⇄ 審查計畫（來回修改直到通過）→ 實作 ⇄ 審查程式碼（來回修正直到通過）
```

- **自動指派**：依各家的能力分數、你的偏好（品質優先／平衡／省額度）、登入與額度狀態決定人選；審查者預設和撰寫者不同家；某家失敗或額度用完時自動換下一家。
- **自訂指派**：每個角色自己選供應商，並可覆寫模型與推理強度。
- **每個階段都能開關**：在「工作流設定」可以分別關掉計畫、計畫審查、實作、程式碼審查。簡單任務關掉計畫就會直接實作；只想要一份計畫可以關掉實作。
- 達到回合上限或卡住時會暫停，讓你決定要再給幾輪、直接接受或停止；勾「審查通過後先問我」則每個階段結束都會先問你。
- 對話結束後可以在同一個對話繼續下指令，沿用相同角色與資料夾。

## 對話中的控制

| 動作 | 怎麼做 | 效果 |
|---|---|---|
| 暫停 | agent 工作中按 **❚❚** | 正在工作的 agent 立刻停下，還沒開始的 agent 也會等待；已經完成的工作都會保留 |
| 繼續 | 暫停後按 **▶** | agent 從原本的進度接著做（能接續工作階段的工具會沿用同一個 session）。暫停時在輸入框打的文字會一起交給 agent，可以用來補充或修正方向 |
| 停止 | 標題列的「停止」 | 結束整個工作流（暫停中也可以停止） |
| 編輯已送出的訊息 | 滑到自己的訊息，按「編輯」 | 修改後送出：如果工作流還在跑，會先立即中斷，再用修改後的內容開一個新的工作流（設定相同）。舊的對話留在紀錄中，兩邊會互相標示 |
| 調整設定 | 工作中也能按 ⚙ 角色／權限 | 角色、模型、階段開關、sub agent、權限、上下文分享、顧問等，套用到接下來開始的 agent；換掉某個角色的供應商時，該角色會用新的工作階段開始 |
| 自動 ↔ 自訂指派 | ⚙ 角色 | 對話中隨時可以在自動與自訂指派之間切換 |

## 顧問模式

在輸入框的「💡 顧問」按鈕直接切換（桌面版與瀏覽器版；VS Code 版維持精簡，請在「工作流設定 → 顧問模式」切換），預設關閉：

| 模式 | 說明 |
|---|---|
| 關閉 | 不使用顧問 |
| Claude 原生 | 只對 Claude Code 的 agent 生效，使用 Claude 官方的 advisor（可選顧問模型，例如 Opus）。由 Claude 自己決定何時請教，建議內容是加密的，畫面上看不到 |
| 跨家顧問 | 每一家的 agent 卡住時都能呼叫 `ask_advisor`，請教你指定的供應商與模型（例如 Codex 做事、Claude Opus 當顧問）。顧問是唯讀的，只給建議不改檔；建議會顯示在對話中並記進共用筆記。可設定每次對話最多請教幾次（預設 5 次），每次請教都會把過程交給顧問，比較耗額度 |

## 權限與安全

| 等級 | 行為 |
|---|---|
| 📋 Plan 唯讀 | 只能讀檔與規劃，不改檔、不執行有副作用的指令 |
| ✋ 手動核准 | 每次改檔或執行指令都會在對話中跳出核准卡片（允許／這次對話都允許／拒絕） |
| ✏️ 自動編輯 | 工作資料夾內的編輯自動允許；執行指令依各家沙箱限制或被擋下 |
| ⚡ 完全 Auto | 全部自動核准（Codex 仍保留工作資料夾沙箱） |

- 目前只有 Claude Code 能在 headless 模式逐項詢問；其他工具選「手動核准」時會改用各自最接近的安全設定，設定視窗中會明確提示。
- **隔離模式**：agent 在獨立的 git worktree 副本中工作，完成後你再決定「套用到我的專案」「保留為 git 分支」或「捨棄」，不會直接動到你的檔案。
- **sub agent 不會比上層權限大**：唯讀的 agent 只能派出唯讀的 sub agent；「手動核准」時，派出 sub agent 也要你先核准，核准卡片會註明該工具能不能逐項詢問。
- **截圖的範圍**：本機檔案只能截取工作資料夾內的檔案（不能是資料夾），外部網站在「Plan 唯讀」下不允許、在「手動核准」下要你核准；localhost 開發伺服器不受限。
- **「這次對話都允許」的範圍**：指令類工具只涵蓋同一個程式（允許 `npm test` 不代表允許 `curl`），串接的指令只涵蓋完全相同的那一行。
- Aivenue 自己執行 git 時會關閉 hooks、fsmonitor 與外部 diff；若 agent 在工作中改動了 git 設定，Aivenue 會改用不呼叫 git 的方式整理變更。

## 額外資料夾

除了工作資料夾，還可以在「工作流設定 → 額外資料夾」加入其他資料夾（可以加很多個，最多 20 個），例如函式庫的原始碼、文件、另一個相關專案。所有 agent（包括 sub agent 和顧問）都能自己讀取、搜尋和探索這些資料夾，不需要把檔案一個個附上，就像 Claude Code 的 `--add-dir`。

- 加入方式：按「瀏覽…」選資料夾，或貼上完整路徑後按 Enter；每個資料夾都可以單獨移除。
- 對話進行中也能增減，從下一個開始的 agent 起生效。
- agent 會把它們當參考資料，除非你要求，不會修改裡面的檔案。
- 各家的做法：Claude Code、Antigravity、Copilot 用 `--add-dir`，Qwen Code 用 `--include-directories`，OpenCode 開放讀取工作資料夾以外的路徑，Codex 的沙箱本來就能讀取。
- 截圖工具也能截取這些資料夾裡的 HTML 或圖片。

## Sub agent（跨家分工）

- 在「工作流設定 → Sub agents」打開並勾選允許被調用的供應商；任何角色在工作中都能把子任務派給它們，子任務的進度會顯示在呼叫者卡片的下方。
- **可以指定 sub agent 用的模型與推理強度**：每個被允許的供應商下方都有模型選單；指定後呼叫者無法更改，沒指定時呼叫者可自行選擇，否則用該供應商的預設。
- 可設定最多巢狀層數與同時執行上限。
- **Agent map**：開啟 sub agent 的對話，標題列會出現「Agent map」按鈕（數字是 sub agent 數量，執行中會有閃爍的點）。點開會看到所有 agent 的樹狀圖：誰派出誰、每個 agent 是哪一家哪個模型、花了多久、用了多少 token、現在正在做什麼。點任何一個 agent 可以看到它的任務、由誰派出、token 明細（輸入／快取／輸出）、派出的下一層 agent、結果全文、改動的檔案和完整的處理過程。

## GitHub

「設定 → 能力 → GitHub」三個步驟，全部一鍵完成：

1. **安裝 Git 與 GitHub CLI**：按「一鍵安裝」（Windows 用 winget、macOS 用 Homebrew、Linux 用系統的套件管理員）。
2. **登入 GitHub**：按「登入 GitHub」，會開啟 GitHub 官方的瀏覽器登入頁，輸入終端機顯示的一次性代碼即可；Aivenue 不經手你的密碼。登入後 git 推送也使用這個帳號。
3. **GitHub 工具（選用）**：一鍵啟用 GitHub 官方的 MCP 工具，所有供應商的 agent 都能直接查 issue、PR、程式碼與 CI。沿用上面的登入，不用另外申請 token；預設唯讀。

登入後，agent 會知道可以用 `gh` 指令操作 GitHub（開 PR、看 CI 失敗原因等）。

**對外動作一律先問你**：推送、建立儲存庫、開 / 合併 Pull Request、留言、發布版本、部署等會改變外部的動作，agent 都必須先在對話中跳出核准卡片，你允許後才會執行，不論權限設定為何；你拒絕的話，agent 不會執行，也不會改用其他方式繞過。讀取（fetch、pull、查看 PR / issue / CI）不需要核准。

## 截圖預覽

任何一家 agent 都能呼叫 Aivenue 內建的 `capture_screenshot`，把網頁、本機 HTML 檔或開發伺服器（例如 `http://localhost:5173`）拍成截圖：

- 截圖直接顯示在該 agent 的卡片裡，點一下可放大；agent 自己也能打開截圖檢查版面。
- 可指定寬高（例如 390 寬模擬手機）與等待時間（讓動畫或資料載入完成）。
- 實作者做完畫面會自己拍照確認；審查者也會看截圖驗收。你也可以直接在任務裡要求「做完拍一張給我看」。
- 使用電腦上的 Edge 或 Chrome 以無頭模式拍攝，每次用全新的臨時設定檔，不會碰到你的瀏覽器資料；找不到時可用環境變數 `AIVENUE_BROWSER` 指定瀏覽器路徑。
- 截圖存在工作資料夾的 `.aivenue/screenshots/`（已自動加入 `.gitignore`），對話紀錄裡也保留一份。

## 瀏覽器工具（一鍵啟用）

在「設定 → 能力 → 共用 MCP 伺服器」可以一鍵啟用兩個瀏覽器工具，啟用後所有供應商的 agent 都能使用：

| 工具 | 用途 |
|---|---|
| Playwright | 操作網頁：開網址、點擊、輸入、填表單、換頁、讀取頁面內容 |
| Chrome DevTools | 除錯網頁：console 錯誤、網路請求、效能分析、執行 JavaScript |

- 兩者都使用獨立、用完即丟的瀏覽器設定檔，不會用到你平常登入帳號的瀏覽器。
- 可勾選「顯示瀏覽器視窗」看 agent 操作，預設在背景執行。
- 沒有安裝 Chrome 時會改用 Edge；第一次使用時會自動下載工具（需要 Node.js）。
- 預設不開啟：每個開啟的工具都會讓每個 agent 多讀一批工具說明，用掉 context 與額度，需要時再開即可。

## 共用上下文

agent 之間預設會交接計畫、審查意見與摘要，並看得到其他 agent 做了什麼與共用筆記（📌）。需要細節時，任何 agent 都能用 `read_context` 讀取其他 agent 的完整紀錄（回覆、指令與輸出），也能用 `post_note` 留筆記給後面的人。在「工作流設定 → 上下文分享」可以改成「只交摘要」或「完整紀錄」（把上一棒的完整紀錄直接交給下一棒，最多 100 萬字）。

## 支援的工具

| 工具 | 訂閱登入 | API 金鑰 | 安裝指令 |
|---|---|---|---|
| Claude Code | Claude Pro / Max | Anthropic API | `npm install -g @anthropic-ai/claude-code` |
| Codex | ChatGPT Plus / Pro | OpenAI API | `npm install -g @openai/codex` |
| Antigravity（`agy`） | Google AI Pro / Ultra | — | Windows：`winget install --id Google.AntigravityCLI -e`<br>macOS / Linux：`curl -fsSL https://antigravity.google/cli/install.sh \| bash` |
| GitHub Copilot CLI | Copilot Pro / Pro+ / Business | 自帶金鑰（BYOK） | Windows：`winget install --id GitHub.Copilot -e`<br>macOS / Linux：`npm install -g @github/copilot` |
| OpenCode | 內建免費模型，另可接上百家 API 與訂閱方案（Kimi、通義、GLM、MiniMax…） | ✓ | `npm install -g opencode-ai` |
| Qwen Code | QwenCloud Token Plan | 任何 OpenAI 相容 API | `npm install -g @qwen-code/qwen-code` |

也可以在「設定 → 供應商與帳號 → 新增」從清單加入其他 API／訂閱方案，或自訂任何有命令列模式的 CLI。

### 同一個工具登入多個帳號

例如你有兩個 Claude 訂閱，可以兩個都登入並同時使用：「設定 → 供應商與帳號」展開該工具 →「其他帳號」→ 輸入名稱並「新增帳號」，再在新的那一列按「登入」。

- 每個帳號有自己獨立的登入資料，會變成一個獨立的供應商，可以同時指派到不同角色或當 sub agent。
- 自動指派會把同一個工具的不同帳號視為「同一家」（審查者仍會換成別家）；某個帳號額度用完時會自動換到另一個帳號。
- 支援：Claude Code、Codex、GitHub Copilot CLI。OpenCode 的 API／訂閱方案可以重複加入，每一個就是一個帳號。
- Antigravity 的登入存在作業系統的鑰匙圈，無法分開，只能用一個帳號。
- 移除帳號時可以選擇是否一併刪除它在這台電腦上的登入資料。

## 附件

程式碼、文字、CSV、JSON、Markdown 等所有 agent 都能讀；圖片交給能看圖的 agent；PDF、Word、Excel、PowerPoint、OpenDocument、Jupyter 由 Aivenue 轉成文字；ZIP 自動解壓。讀不到的檔案（例如某家不支援的音訊）會被明確告知 agent，輸入框也會提醒你。

## 設定與資料

| 設定 | 說明 |
|---|---|
| `aivenue.openOnStartup` | VS Code 啟動時自動開啟 Aivenue 面板（預設關閉） |

| 指令 | 說明 |
|---|---|
| Aivenue: 開啟 Aivenue | 開啟右側面板 |
| Aivenue: 在編輯器分頁中開啟 Aivenue | 寬版面 |
| Aivenue: 在瀏覽器中開啟 Aivenue | 在瀏覽器中使用同一個工作階段 |

- 對話紀錄、設定、用量統計存在這台電腦的 `~/.aivenue/`（可用環境變數 `AIVENUE_HOME` 改位置）。
- API 金鑰存在 VS Code 的 SecretStorage（作業系統加密），不會寫進設定檔。
- Aivenue 只在本機的 127.0.0.1 開服務，並用隨機權杖保護。
- 為了讓 agent 回報結果，Aivenue 會在部分工具的設定中加入自己的 MCP 項目（例如 Antigravity 的 `~/.gemini/config/mcp_config.json`，以及只允許 Aivenue 自己工具的 `mcp(aivenue/*)` 規則）；不會改動其他設定。

## 常見問題

**一定要安裝 Aivenue 桌面 App 嗎？**
不用。插件可以單獨使用；只要這台電腦有安裝並登入你要用的 AI 工具即可。

**額度會怎麼算？**
每家工具都用你自己的帳號或金鑰，額度照各家規則計算。設定 → 用量可以看每家的使用紀錄，Codex 會即時讀取官方額度（5 小時與每週上限）。用量每 5 分鐘自動更新；打開用量頁時會立刻重新掃描，停留期間每分鐘更新，也可以按「重新整理」。

**每一輪都會重新啟動 CLI 嗎？**
不會。支援多輪輸入的工具（Claude Code、Antigravity）在同一段對話中會沿用同一個執行中的 CLI，卡片上會顯示「↻ 沿用執行中的 CLI」，省下啟動時間；對話閒置超過 5 分鐘才會關閉。其他工具每輪會用同一個 session 接續。

**為什麼選了「手動核准」，某家還是自己做了？**
除了 Claude Code 之外，各家的 headless 模式無法逐項詢問，Aivenue 會改用最接近的安全設定（例如只允許編輯、禁止執行指令），設定視窗會標示。需要完全掌控時，請搭配隔離模式。

**Remote / WSL / SSH 可以用嗎？**
可以。插件會在遠端執行，AI 工具需要裝在遠端那台機器上。「安裝」「登入」都會在 VS Code 內建的終端機執行，所以連到沒有桌面的伺服器也能用。

**Linux / macOS 要注意什麼？**
- 「安裝」按鈕會自動使用該平台的安裝方式（見上表）。
- 用 npm 安裝的工具需要 Node.js；如果 Node.js 是用系統套件管理員裝的（例如 `apt install nodejs`），npm 的全域資料夾需要 sudo，安裝前會先檢查，並告訴你怎麼處理（建議改用 nvm，或把 npm 全域資料夾改到家目錄），不會直接丟出 npm 的 EACCES 錯誤。
- Aivenue 會讀取登入 shell 的 PATH，所以用 nvm、fnm 或 `~/.local/bin` 安裝的工具也找得到。
